# 電價功能與實際費率擴充紀錄

更新日期：2026-10-17（Asia/Taipei）。

## 第二階段現況

已實作台電住宅非時間電價、簡易二段式與三段式，來源為 [台電 JSON](https://service.taipower.com.tw/data/opendata/apply/file/d007008/001.json)，實施日 2025-10-01、查核日 2026-10-17。操作與來源限制見 [PHASE2_GUIDE.md](PHASE2_GUIDE.md)，固定資料與整合驗收見 [PHASE2_VALIDATION.md](PHASE2_VALIDATION.md)。

使用日曆月「不含本系統任務」的基準用電，跨月拆算流動電費差額。住宅採累進級距，簡易時間電價包含夏月／台電離峰日／分段時段及超過 2,000 度加收。家庭總額合併任務負載，核准時核對基準、來源與預約負載版本。保留模擬模式、來源快照及顯式更新；下載失敗保留既有來源，不靜默降級。

正式時間電價日曆覆蓋 2026、2027。2026 官方 PDF 的原下載端點失敗，以索引表格核對；2027 PDF 已下載、解析並目視查核，provenance 記錄於資料檔。缺少適用日曆或基準時停止估算。固定基本費、完整帳單與實際抄表週期比例計費未實作。

## 已確認方向

- 系統以實際應用為主，先完成洗衣機排程與執行回報，再延伸冷氣管理。
- 首版使用模擬尖峰／離峰價格，在使用者允許的時間範圍內安排洗衣，並於執行前確認計畫。
- 日常使用採真實時間，另提供加速模擬供展示與測試。
- 實際費率增量估算已完成上述三方案；此文件繼續追蹤完整帳單範圍。
- 冷氣監測 PoC 已延伸為可核准的洗衣與冷氣控制系統。

## 首版模擬電價

- 畫面及計畫明確標示「模擬電價」與「預估費用」。
- 費率統一以 NT$/kWh 表示，時段採 Asia/Taipei。
- 以完整洗衣行程跨越的各時段功率、時間與費率計算預估費用，而非只看啟動時的價格。
- 已接受的模擬費率：08:00–22:00 為 NT$6/kWh，其餘時段 NT$2.5/kWh；可調整，不得宣稱是台電正式費率。
- 排程的預估費用與依執行遙測累積的模擬費用分開呈現。
- 加速展示時，排程、洗衣進度與用電積分使用相同的模擬時間；連線存活與訊息過期另用真實時間判斷。

## 實際電價階段的驗收重點

- 每筆計算可追溯至適用方案、生效期間及官方來源。
- 驗證跨費率時段、午夜及適用季節／假日邊界的用電與費用拆分。
- 對已實作的正式計費規則，以人工可核算的案例檢查金額。
- 畫面能清楚區分模擬價格、正式費率下的估算，以及完整帳單計算。
- 固定單價且用電量相同的案例，移動啟動時間不應產生虛假的電費節省。
- 正式費率不可用時，不可靜默換成模擬數據並沿用正式電價標示。
