# 電價功能與實際費率擴充紀錄

更新日期：2026-10-16（Asia/Taipei）。

## 已確認方向

- 系統以實際應用為主，先完成洗衣機排程與執行回報，再延伸冷氣管理。
- 首版使用模擬尖峰／離峰價格，在使用者允許的時間範圍內安排洗衣，並於執行前確認計畫。
- 日常使用採真實時間，另提供加速模擬供展示與測試。
- 後續需要延伸實際電價；此文件作為持續追蹤的需求紀錄。
- 本文件記錄後續需求；目前已完成的 PoC 仍是冷氣能源監測。

## 首版模擬電價

- 畫面及計畫明確標示「模擬電價」與「預估費用」。
- 費率統一以 NT$/kWh 表示，時段採 Asia/Taipei。
- 以完整洗衣行程跨越的各時段功率、時間與費率計算預估費用，而非只看啟動時的價格。
- 已接受的模擬費率：08:00–22:00 為 NT$6/kWh，其餘時段 NT$2.5/kWh；可調整，不得宣稱是台電正式費率。
- 排程的預估費用與依執行遙測累積的模擬費用分開呈現。
- 加速展示時，排程、洗衣進度與用電積分使用相同的模擬時間；連線存活與訊息過期另用真實時間判斷。

## 後續：接入實際電價

實作時先確認適用方案，再查驗當時的官方資料。不能只把範例價格替換成某個數字就宣稱支援實際電費。

- [ ] 確認使用者適用的住宅用電方案，以及需要的計費週期與用電資料。
- [ ] 查驗台電官方公布的適用費率、時段及生效日期，記錄來源 URL 與查核日期。
- [ ] 依適用方案確認是否涉及季節、平假日、時間電價、級距、基本費或其他計費項目；只實作已確認適用的規則。
- [ ] 區分「提供排程用的時段價格」與「計算整期帳單」；級距或其他整期計費條件不能一律當成固定的單一時段單價。
- [ ] 定義估算單一洗衣行程費用所需的已知資料，並在資料不足時顯示估算限制。
- [ ] 讓排程邏輯透過統一的電價介面取得資料，保留模擬與實際方案的切換位置；具體型別於實作設計時確定。
- [ ] 每份計畫與費用紀錄保留採用的方案／費率版本，讓歷史結果可追溯。
- [ ] 確定費率更新方式，以及正式電價資料缺失或過期時的處理規則。

## 實際電價階段的驗收重點

- 每筆計算可追溯至適用方案、生效期間及官方來源。
- 驗證跨費率時段、午夜及適用季節／假日邊界的用電與費用拆分。
- 對已實作的正式計費規則，以人工可核算的案例檢查金額。
- 畫面能清楚區分模擬價格、正式費率下的估算，以及完整帳單計算。
- 固定單價且用電量相同的案例，移動啟動時間不應產生虛假的電費節省。
- 正式費率不可用時，不可靜默換成模擬數據並沿用正式電價標示。

## 尚待決定

實際電價方案、費率更新方式，以及是否計算完整帳單，均需在對應階段進一步確認。
