# 家庭助理操作

開啟 `http://127.0.0.1:8502` 後，右側家庭助理可以直接輸入多設備需求，例如：「幫我開冷氣、安排洗衣，燈調到 40% 暖光」。同一個 CopilotKit Sidebar 會顯示 Agent 處理狀態與已保存的設備計畫卡；點擊 3D 設備或設備清單則開啟左側操作抽屜。

冷氣與洗衣是兩張獨立計畫卡，必須分別核准。核准後 Controller 才會依 MQTT 或 Matter 傳輸控制設備。燈泡明確指令會排入原有燈泡控制佇列，收到狀態回報後更新場景；送入佇列本身不代表燈泡已完成操作。

## 預設與確認

- 冷氣預設 27°C、舒適範圍 26–28°C、運轉一小時。未指定開始時間時，在使用者核准後才啟動計時；指定預約時間則沿用該時段。
- 洗衣預設 24 小時內完成、避開 23:00–07:00，並優先安排較低估算費用的合法時段。
- 「修改計畫」會將補充需求連同任務 ID 與版本交回既有 Agent。若任務版本已變更，舊卡片無法核准。
- 可取消尚未啟動任務；執行中的設備需再次確認中止。只有設備回報能確認停止或完成。
- 故障與未知狀態要先查核；人工確認設備後才可解除異常。

## 用電、偏好與診斷

頂部導覽可切換用電紀錄、偏好設定與系統診斷。用電頁顯示最近功率樣本、家庭核准任務增量費用與近期任務；偏好頁可保存冷氣與洗衣預設、費率方案、逐月基準用電與展示時鐘倍率，並要求更新台電費率來源。缺少指定月份基準時，正式費率估算會依原規則要求補齊。

診斷頁提供本機傳輸狀態、Agent／工具、設備命令、請求佇列與稽核紀錄。畫面透過 FastAPI 讀取資料；所有設備操作仍經既有持久化請求與 Controller 驗證。

## 啟動

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[web]"
npm.cmd ci --prefix web
npm.cmd run build --prefix web
.\scripts\start.ps1 -Transport mqtt
```

家庭入口固定預設為 8502，Copilot Runtime 為 8503。既有 `-With3D` 啟動參數仍可使用，但不再另開第二個 UI。停止時執行 `scripts/stop.ps1`；只關閉瀏覽器不會停止背景 Agent 或設備排程。
